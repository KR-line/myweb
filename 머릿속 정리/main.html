SQL 정리하기

  • 1. A 테이블 만들기 (이름은 A, no 은 숫자 char는 문자열 time은 날짜로)


  • 정답 : CREATE TABLE example( no NUMBER, name VARCHAR2(20), now DATE );

  • 2. A 테이블에 행 추가하기 (1, 2, 3 모두 추가)


  • 정답 : INSERT INTO A (no, name, now) VALUES (1, '가', SYSDATE);

  • 3. A 테이블 칼럼 수정하기 (no 1 을 4 로 수정)


  • 정답 : UPDATE A SET no = 4 WHERE no = 1;

  • 4. A 테이블 칼럼 삭제하기 (no 4인 칼럼 삭제)


  • 정답 : DELETE FROM A WHERE no = 4;
